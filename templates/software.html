Far Reach Co.

Virtual tabletop / real-time web / SaaS

An online tabletop for running role-playing sessions without account friction.

Players can join by link, move through maps, roll dice, manage tokens, and keep longer campaigns in persistent shared spaces. Far Reach is built around actual table flow: quick entry, campaign records, character sheets, assets, permissions, and synchronized tabletop audio.

Contains: real-time maps, persistent Wyrlds, shared assets, recruiting controls, D&D 5E sheets, synced music

Parch

Encrypted chat / self-hosted / Go / SQLite

A self-hosted messenger for people who want to keep the keys close.

Parch is built around end-to-end encryption, public-key identity, and user-owned hosting. The current project focuses on encrypted messaging with a Linux CLI host client and local SQLite storage.

Contains: Go relay service, Ed25519 auth, ECDH P-256 encryption, replay prevention, local SQLite storage, systemd deployment

Desktop Tools

Tape Sim

C / SwiftUI / PortAudio

A multitrack recorder shaped like a small tape machine.

Tape Sim keeps recording direct: rewind, fast-forward, RTZ, stereo bounce, keyboard shortcuts, and 48kHz 24-bit WAV capture. It supports as many simultaneous tracks as the connected audio interface can handle.

Contains: real-time audio in C, SwiftUI controls, PortAudio device handling, simple file/session management
Download for macOS GitHub

CSV Zero

Python / Tkinter

A small CSV editor for plain inspection and quick repair.

CSV Zero detects delimiters and encoding, searches across all data, and keeps insert, edit, and remove operations direct. It is meant for moments when opening a full spreadsheet app feels heavier than the task.

Contains: format detection, session memory, keyboard shortcuts, packaged Windows installer
Download for Windows GitHub

Mayura English Patch

Windows / Ukagaka / localization

An English patch for a classic Japanese desktop ghost.

The Mayura patch preserves the original installation, creates a separate English copy, and includes a guided Windows installer. It treats the old desktop companion as something to be handled carefully, not overwritten.

Contains: context-aware dialogue translation, original behavior preserved, reversible patch installation
