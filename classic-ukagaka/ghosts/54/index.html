Classic ghost directory / 54

54 ５４

An unusual classic centered on a quiet girl whose original appearance is drawn as large-scale ASCII art. The later bundled MIY Color shell gave 54 a more conventional illustrated form, and a remarkable number of artists subsequently created alternate shells for her.

Technical context

The original 54 uses an ASCII-art default shell derived from work by D4 北野チェき, with permission recorded in the package readme. The archive also bundles the widely recognizable MIY Color shell by みやま / MIY. Package metadata names the secondary character slot 540, though surviving documentation does not describe 540 as a conventional visible companion.

Related projects

  • AG36's Project54 / 54みたいの

    AG36 states that this project diverged from a planned port of 54 and became a separate derivative ghost, described as 54's unrelated younger sister. It is not a replacement release of the original.

Scope & method
This index covers ghosts first released-or independently documented as existing-from 2000 through 2007. Later updates and official redistributions remain part of those ghosts’ records. Sources accompany each entry, and undocumented details are marked unknown. Packages are preserved only when redistribution permission is documented.
