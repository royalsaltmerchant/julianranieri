Beeta β

A brightly colored early ghost based on an abandoned candidate for Nanika's default character artwork. Beeta appears in a yellow and black outfit with the small companion Unyuu G and became a separately distributed character in September 2001.

Technical context

Beeta is a derivative of β-RC2, an unfinished surface designed by Tsukurimonoji as a proposed default character for Nanika. The distributed edition uses redrawn artwork by WSplus. Its readme credits WS plus and Ryo-ma for the port, identifies an earlier ghost file by 閑馬永空, and places distribution responsibility with Ryo-ma.
