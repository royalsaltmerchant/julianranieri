Preview release

What is in the download?

The current ZIP contains a transparent, script-based Windows patcher—not a conventional signed installer yet.

  • Install-Mayura-English.cmd starts the patcher.
  • Install-Mayura-English.ps1 verifies Mayura, preserves save data, and creates the English copy.
  • patch-manifest.json contains the translation patch data and file checksums.
  • README.txt contains installation instructions, permission terms, and credits.

Translation process

Dialogue translated in context.

Mayura’s dialogue was divided into related conversations and features instead of translated as disconnected lines. Language models produced English drafts with surrounding dialogue and script context; the results were reviewed during live use, revised when problems appeared, and checked automatically to ensure the original ghost’s commands and structure remained intact.
